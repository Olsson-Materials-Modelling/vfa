# Convention data

`covalent_radii.json`: covalent radii (A) of Cordero et al., Dalton Trans. 2008, 2832, Table 2, for 74 elements from H to Bi (not
Tc, Ru, Rh, Pd, Pm, Tm, Re, Os, Ir); carbon is the sp3 value (sp2 0.73, sp 0.69); Mn, Fe and Co are the low-spin values (high spin
1.61, 1.52, 1.50).
`ionic_radii.json`: effective ionic radii (A) of Shannon, Acta Cryst. A32, 751 (1976), one entry per species with the charge and
coordination number it holds for; a species in another state needs its own value.
`masses.json`: standard atomic weights of the same 74 elements, abridged to five significant figures, from Prohaska et al., Pure
Appl. Chem. 94, 573 (2022) (IUPAC 2021).

What each convention measures: docs/conventions.md in the repository.
