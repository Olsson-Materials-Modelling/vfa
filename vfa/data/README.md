# Convention data

`covalent_radii.json`: covalent radii (A) of Cordero et al., Dalton Trans. 2008, 2832, Table 2; carbon is the sp3 value (sp2 0.73, sp 0.69); Mn, Fe and Co are the low-spin values (high spin 1.61, 1.52, 1.50).
`ionic_radii.json`: effective ionic radii (A) of Shannon, Acta Cryst. A32, 751 (1976), one entry per species with the charge and
coordination number it holds for; a species in another state needs its own value.
`masses.json`: standard atomic weights, IUPAC 2021, abridged to five significant figures.

What each convention measures and when it fails: docs/conventions.md.
